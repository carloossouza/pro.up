Como Hospedar Gratuitamente no GitHub Pages

Este sistema foi construído em um **único arquivo HTML** totalmente autônomo. Ele funciona 100% no navegador e salva dados no `localStorage` local.

  1. Crie uma conta no site GitHub.com (caso não possua).
  2. Crie um repositório público com o nome que desejar (exemplo: pro-up-gestao).
  3. Faça o upload do arquivo: renomeie este arquivo baixado para index.html e faça upload na raiz do repositório.
  4. Ative o GitHub Pages: Vá em Settings (Configurações) > Pages > em Source selecione a branch main e clique em Save.
  5. Pronto! Em 1 minuto seu sistema estará no ar na URL gratuita:
    https://seu-usuario.github.io/pro-up-gestao/
Dica de Sincronização de Dados: Como os dados ficam no navegador, você pode usar o botão de Exportar JSON no topo do painel para criar cópias de segurança e compartilhar dados atualizados com sua equipe a qualquer momento.
